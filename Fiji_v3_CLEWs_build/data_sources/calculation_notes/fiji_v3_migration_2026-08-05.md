# Fiji v3 identity migration

Fiji v3 inherits the complete Fiji v2.9 canonical package and retained
evidence. The portable case changes only its directory identity,
`osy-casename`, local README, and empty result registry. Every editable model
parameter file is byte-for-byte unchanged, and generated solver inputs and
results are excluded. Git tag `v2.9.0` preserves the numerical predecessor.
