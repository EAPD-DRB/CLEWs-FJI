# Portable raw MUIO case

`Fiji_CLEWs_Global_raw-v1.0.0_MUIO.zip` is the immutable raw Fiji reference
case. It is technically solved but historically uncalibrated.

Extract the contained `Fiji_CLEWs_Global` folder into
`MUIOGO/WebAPP/DataStorage/`. Generated solver inputs and results are
excluded.

The SHA-256 checksum is recorded in `SHA256SUMS`.
