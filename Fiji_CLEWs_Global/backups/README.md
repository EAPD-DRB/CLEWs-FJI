# Fiji baseline backups

These archives freeze the model immediately before adoption of the Philippines
v12 tracking structure on 25 July 2026.

- `Fiji_CLEWs_Global_source_raw_pre_tracking_2026-07-25.zip` contains the raw
  build package before its documentation and evidence were reorganized.
- `Fiji_CLEWs_Global_MUIO_raw_pre_tracking_2026-07-25.zip` is the portable raw
  MUIO case at the same point.

They are recovery artifacts, not active working copies. Later calibration
milestones should receive new dated backups rather than overwriting these.
